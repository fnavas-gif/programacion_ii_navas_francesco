# Programación II

Repositorio de trabajo para la materia **Programación II**.

En este repositorio se almacenarán los proyectos, prácticas, ejercicios y subproyectos desarrollados durante el semestre, utilizando principalmente **Python, Django y Odoo**.

## 📚 Contenido

### 🐍 Python

Ejercicios y proyectos desarrollados con Python, incluyendo:

- Fundamentos de programación
- Programación orientada a objetos
- Manejo de archivos
- Módulos y paquetes
- Manejo de excepciones
- Desarrollo de pequeños proyectos

### 🌐 Django

Proyectos web desarrollados con el framework Django.

Se incluirán temas como:

- Creación de proyectos y aplicaciones
- Modelos y bases de datos
- Vistas y URLs
- Plantillas
- Formularios
- Administración de Django
- Desarrollo de aplicaciones web

### 🟣 Odoo

Proyectos y módulos desarrollados utilizando Odoo.

Se trabajará principalmente con:

- Creación de módulos
- Modelos
- Vistas
- Menús y acciones
- Seguridad y permisos
- Integración con Python
- Desarrollo y personalización de módulos

Mantener organizados los trabajos de **Programación II** y llevar un control de los proyectos y subproyectos realizados durante el semestre.

Cada proyecto tendrá su propia carpeta y podrá contener sus respectivos archivos, recursos, documentación y código fuente.
